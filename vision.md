# Alphag — vision

## Цель

Сделать **простой web-инструмент для исследователей**, который помогает понять, **как мутация меняет regulatory-сигнал ДНК** (DNase через AlphaGenome) — без Colab и без написания Python-кода каждый раз.

Не коммерческий SaaS и не «официальный Google-продукт», а **удобная оболочка (BYOK)** над AlphaGenome API для non-commercial research.

---

## Аудитория

**Основная:**

- биоинформатики и molecular biologists с **своим AlphaGenome API key**;
- студенты и lab mates, которым нужно быстро сравнить **reference vs mutant**;
- коллеги, которым нужно демо «что делает вариант в regulatory-контексте».

**Не целевая:**

- широкая публика «с улицы»;
- клиники для диагностики;
- batch на тысячи вариантов (API для этого не про масштаб).

---

## Критерий успеха

Проект считается успешным, если **реальный researcher** (не только автор) может:

1. Открыть сайт, ввести **свой ключ** и две последовательности (ref + mut).
2. Нажать **Compare** и получить **понятную таблицу Δ** (mean, max, сдвиг пика).
3. Использовать результат в работе — скопировать, положить в отчёт или обсудить с коллегой — **без второго прогона вручную**.

**Количественно (реалистично):** хотя бы **5–10 человек вне автора** воспользовались compare за первые 2–3 месяца после деплоя — или инструмент регулярно используется в одной lab / для демо.

## 3 конкретных шага

### 1. Задеплоить ref vs mutant на Render

- Запушить текущий код (режим Compare, disclaimer, BYOK).
- Обновить README под новый flow.
- Проверить live URL: compare работает с реальным ключом.

**Готово, когда:** `https://alphagenomio.onrender.com/` показывает Compare и таблицу Δ.

### 2. Добавить выбор ткани

- Dropdown: lung, liver, brain (3–5 UBERON terms).
- Одна и та же ткань для ref и mut в compare.

**Готово, когда:** пользователь может выбрать ткань и получить результат не только для lung.

### 3. Export + примеры для демо

- Кнопка **Download CSV** для таблицы Δ.
- 1–2 пресета ref/mut («Insert example») для быстрого sanity-check.

**Готово, когда:** результат compare можно скачать и показать коллеге за 30 секунд без копипасты.

## Чего не делаем (пока)

- Платный SaaS на AlphaGenome API.
- Несколько моделей (SpliceAI, CADD…) — только после того, как compare стабилен.
- Свой GPU / self-hosted AlphaGenome — отдельный проект, если понадобится позже.
